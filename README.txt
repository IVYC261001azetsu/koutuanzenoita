おおいた交通安全マップ（拡張試作版）
====================================

【起動】
1. ZIPを展開します。
2. index.htmlをブラウザで開きます。
3. 地図・グラフの読み込みにはインターネット接続が必要です。

【ファイル】
- index.html：画面
- style.css：デザイン
- app.js：地図・フィルター・グラフ
- README.txt：この説明

【収録した分析】
- 65歳以上の事故・死亡・重傷（令和6年値と令和7年値を区別）
- 死亡・重傷事故の全体像
- 交差点・死角（建物・植木・駐車車両）
- 車の速度・交差点進入速度
- 朝・夕方・夜間、昼夜別の事故・死者数
- 事故原因・違反分類と独自危険度評価

【重要なデータ上の注意】
このアプリはユーザー提供の調査文に記載された数値を試作データとして入力したものです。公表・提出前に大分県警察の原資料で数値、定義、対象期間を照合してください。
特に、時間帯別死者数の合計、昼夜別の事故件数・死者数、道路形状別件数などは、原資料の集計区分を確認してください。
「死亡者数÷事故件数」は死亡事故率ではありません。事故率を算出するには死亡事故件数が必要です。
建物・植木・駐車車両が原因の事故件数、および実際の交差点進入速度は、提示された県全体の統計だけでは確定できません。
地図のピンは市町村周辺のデモ位置で、実際の事故地点や公式な危険度を示していません。市町村別の危険度を示すには地点別事故データが必要です。
危険度5段階は独自の暫定評価です。
